# content/

Normalized, typed JSON extracted from the old SGSM WordPress site. Everything
here is generated by `scripts/extract-pages.mjs` (pages, news, council,
committees, patrons, partners, past presidents, privileges) except
`site.json`, `media-manifest.json`, `events.json`, `venues.json`,
`gallery.json` and `downloads.json`, which come from other scripts/inputs.

Shapes are authoritative in `.foreman/schemas.md` (Appendix A). This file
just shows one real record from each generated file so the shape is easy to
recognize at a glance.

Regenerate with:

```
node scripts/extract-pages.mjs
```

The script is idempotent — running it again produces byte-identical output —
and safe to re-run any time the files under `<SCRATCH>/wp/` change.

## content/pages/<slug>.json — `PageDoc`

One file per content route (`president-message`, `about-us`, `our-history`,
`sgsm-building`, `collaborative-partnership`, `golfing`,
`hotels-and-restaurants`, `others`, `partners-and-sponsors`,
`world-handicapping-system`, `contact-us`, `news`, `home`). Example —
`content/pages/president-message.json` (truncated):

```json
{
  "slug": "president-message",
  "title": "President's Message",
  "description": "Welcome to Senior Golfer’s Society of Malaysia. We are very proud to be part of a great tradition…",
  "blocks": [
    { "type": "paragraph", "html": "Welcome to Senior Golfer’s Society of Malaysia. We are very <br>proud to be part of a great tradition…" },
    { "type": "heading", "level": 2, "text": "Dato’ Shamsudin Ismail President SGSM" }
  ],
  "hero": {
    "title": "President's Message",
    "image": { "src": "/images/2022/09/president.jpg", "alt": "President, SGSM", "width": 451, "height": 579 }
  }
}
```

`home.json` additionally carries the 7-slide carousel as a single `gallery`
block, and `news.json` (the page, not the top-level file below) is just the
route's own title/heading since the listing itself is served from
`content/news.json`.

## content/news.json — news posts

All 14 WordPress posts, full body converted to `Block[]`. Example (first
entry, truncated):

```json
{
  "id": 2028,
  "slug": "the-mines-resort-country-club",
  "title": "THE MINES RESORT & COUNTRY CLUB",
  "date": "2026-05-21",
  "excerpt": "Malaysia, a land blessed with abundant natural resources, became the world’s largest producer of tin…",
  "category": "golfing",
  "image": null,
  "blocks": [
    { "type": "paragraph", "html": "Malaysia, a land blessed with abundant natural resources…" },
    { "type": "heading", "level": 2, "text": "Privileges" },
    {
      "type": "table",
      "head": ["SGSM Rate", "Published Rate"],
      "rows": [["Weekday <strong>RM 250.00 nett per pax</strong>…", "Weekday <strong>RM 300.00 nett per pax</strong>…"]]
    }
  ]
}
```

`category` is `"news"` for WordPress category 38, `"golfing"` for category
60 (the only two categories actually used by the 14 posts — no post links
from the `hotels-and-restaurants` or `others` privilege pages, since those
two pages are still "under construction" on the source site).

          "title": "D.K.P., D.K., S.S.P.J., D.K.M., D.M.N., …, GRAND CORDON OF THE ORDER OF THE SACRED TREASURE (JAPAN)",
          "image": { "src": "/images/2022/10/dymmtuankusyedsirajuddin2.jpg", "alt": "DULI YANG MAHA MULIA TUANKU SYED SIRAJUDDIN IBNI ALMARHUM TUANKU SYED PUTRA JAMALULLAIL", "width": 577, "height": 919 }

`name` is the honorific style plus the person's name as one line (e.g. "Duli
Yang Maha Mulia …"); `title` carries the post-nominal honours/decorations
where the source lists any.
